# STM32 双轮自平衡车与 NRF24L01 无线遥控系统

基于 **STM32F103C8T6**、**FreeRTOS** 和 **NRF24L01** 开发的双轮自平衡车项目，包含车端控制器与独立无线遥控器两个子工程。车端使用 MPU6050 和双路编码器完成姿态、速度及转向闭环控制；手柄端采集双摇杆四路模拟量，并通过 2.4 GHz 无线链路发送控制指令。

## 功能概览

- 三环 PID 级联控制：角度环、速度环、转向环
- MPU6050 六轴 IMU 采集与互补滤波姿态解算
- 双路编码器测速、PWM 双电机驱动与差速转向
- NRF24L01 双向无线通信；遥控器四路摇杆控制
- 四通道 ADC 摇杆采集、零点偏移、死区与限幅处理
- FreeRTOS 周期任务调度、互斥锁与临界区资源保护
- OLED 实时显示控制参数、传感器/摇杆数据
- 按键启停、车体倾角过大自动停机、串口在线 PID 调参

## 系统架构

```text
│     无线遥控器     │ ──────────────────────────────▶ │            平衡车端           │
│ STM32F103C8T6     │      LH / LV / RH / RV         │ STM32F103C8T6                │
│ 双摇杆 → ADC1     │                                  │ MPU6050 + 编码器 → 三级 PID   │
```


## 硬件组成

| 模块 | 用途 |
| --- | --- |
| STM32F103C8T6 × 2 | 分别作为平衡车端与遥控器端主控 |
| MPU6050 | 获取加速度计、陀螺仪数据，估计车身倾角 |
| 带编码器直流减速电机 × 2 | 车轮驱动与速度反馈 |
| 电机驱动模块 | 接收 PWM 并驱动左右电机 |
| NRF24L01 × 2 | 平衡车与遥控器之间的 2.4 GHz 无线通信 |
| 双摇杆 | 输出四路模拟量控制数据 |
| OLED | 显示 PID 参数、姿态/速度或摇杆数据 |

## 控制逻辑

车端采用三级 PID 级联：

1. **速度环**：使用左右编码器计算平均速度，并输出目标倾角。
2. **角度环**：以 MPU6050 解算出的倾角为反馈，输出基础电机 PWM。
3. **转向环**：以左右轮速差为反馈，输出左右电机差速 PWM。

最终电机输出为：

```text
left_pwm  = angle_pwm + turn_pwm / 2
right_pwm = angle_pwm - turn_pwm / 2
```

控制器对积分与输出进行限幅；当检测到倾角超出 ±50° 时停止电机，防止倒地后持续驱动。

## 遥控数据约定

遥控器每帧发送 4 字节摇杆数据：`LH`、`LV`、`RH`、`RV`。

| 字段 | 车端当前用途 |
| --- | --- |
| `LV` | 映射为速度环目标值，控制前进/后退 |
| `RH` | 映射为转向环目标值，控制左右转向 |
| `LH`、`RV` | 已采集并传输，暂未参与车端控制 |

## FreeRTOS 任务

| 端侧 | 任务 | 职责 |
| --- | --- | --- |
| 平衡车端 | `AnglePIDTask` | 10 ms 采集姿态并执行角度环与电机输出 |
| 平衡车端 | `SpeedPIDTask` / `TurnTask` | 50 ms 更新速度环与转向环 |
| 平衡车端 | `NRFTask` | 接收摇杆数据，更新速度与转向目标 |
| 平衡车端 | `OLEDTask` / `SERIALTask` / `KEYTask` | 状态显示、串口调参与按键启停 |
| 遥控器端 | `ADTask` | 10 ms 轮询四路 ADC 并处理摇杆数据 |
| 遥控器端 | `NRFTask` | 周期发送四路摇杆控制数据 |
| 遥控器端 | `OLEDTask` / `KEYTask` | 数据显示与按键扫描 |

## 构建与烧录

### 开发环境

- STM32CubeMX（用于打开或修改 `.ioc` 配置）
- Keil MDK-ARM（工程中包含 `MDK-ARM` 目录时可直接使用）
- STM32 ST-LINK（烧录和在线调试）

### 步骤

1. 分别打开 `pinghengche/pinghengche.ioc` 与 `pinghengcheshoubin/pinghengcheshoubin.ioc`，确认时钟与外设配置。
2. 使用 Keil 打开每个子工程 `MDK-ARM` 目录中的工程文件，编译并分别下载到车端、遥控器端。
3. 确认两端 NRF24L01 的通道、地址及供电一致；本工程两端使用相同的 5 字节通信地址。
4. 让车轮悬空，先检查 MPU6050 姿态读数、电机方向、编码器计数和遥控器摇杆数据。
5. 从较小 PID 参数开始调试；确认平衡方向正确后再落地测试。

## 调试建议

- OLED 可用于观察车端 PID 参数、目标值、实际值与输出值，或观察手柄的原始/处理后摇杆值。
- 串口支持以滑块类命令在线更新角度、速度、转向 PID 参数和角度偏置，适合配合上位机曲线工具调参。
- 若车体向某侧倾倒时电机进一步加速倒向该侧，请立即断电，并检查 IMU 安装方向、电机正反转和 PID 输出符号。
